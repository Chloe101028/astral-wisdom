⭐CursorEventData

🌸フィールド

フィールド名 型 アクセス 内容
dragging boolean 読み取り専用 現在、ドラッグ中かどうか
touchId integer 読み取り専用 タッチポイントID

🌸メソッド

メソッド 戻り値 内容
CursorEventData:GetUIPos() x, y: number キャンバスの左下を原点として、現在の画面のUI座標を取得します
座標の比率はレイアウト座標と一致します
CursorEventData:GetPressUIPos() x, y: number タッチした画面UI座標を取得します
CursorEventData:GetUIPosDelta() x, y: number 今回のイベントにおける画面UIの移動量を取得します
