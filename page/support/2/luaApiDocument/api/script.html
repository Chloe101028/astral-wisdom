⭐Script

Scriptは現在実行中のLuaスクリプトそのものを表すオブジェクトです。
グローバル変数:Scriptを通じてアクセスできます。

🌸フィールド

フィールド名 型 アクセス 内容
alive boolean 読み取り専用 スクリプトがまだ存在してるかどうか
scriptMappingId integer 読み取り専用 スクリプトのマッピングID
object any 読み取り専用 スクリプトが紐づけられているオブジェクトを取得
path string 読み取り専用 スクリプトのパス
enabled boolean 読み書き可能 スクリプトの有効状態
※script.enabled = false で無効化できます

🌸メソッド

メソッド 戻り値 内容
script:GetParam(paramName: string) any スクリプト変数を取得します
script:Invoke(funcName: string, ...: any) － スクリプト内の関数を名前指定で呼び出します
script:EnableUpdate(enabled: boolean) － ※「3-2.フレーム単位の制御」参照
script:RegisterServerSignalHandler(signalName: string, callback: fun(signalName: string, signalParams: any[])) － 監視するサーバー側から送られる信号を登録します
※コールバックのパラメータは順に信号名、信号引数の配列になります
script:UnregisterServerSignalHandler(signalName: string) － 登録した信号の監視を解除します
script:RegisterCustomVariableChangedHandler(entityType: CustomVariableEntityType, customVariableName: string, callback: fun(entityType: CustomVariableEntityType, customVariableName: string)) － 監視するカスタム変数を登録します
※エンティティタイプと変数名のみがコールバックされるため、現在の値を取得するには 「game.GetGlobalCustomVariableValue」を使用する必要があります
script:UnregisterCustomVariableChangedHandler(entityType: CustomVariableEntityType, customVariableName: string) － 登録したカスタム変数の監視を解除します
