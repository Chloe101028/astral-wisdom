⭐game

gameは、クライアント実行環境が提供するグローバルAPIです。

🌸UIと階層操作

関数 戻り値 内容
game.InstantiateClientUIControl(controlPrefabIndex: integer, parent: ClientUIBaseControl) ClientUIBaseControl 指定したテンプレートインデックスからparentの下にUIを作成します
game.DestroyClientUIControl(control: ClientUIBaseControl) － 指定したUIを破棄します
game.GetClientUIControl(controlId: integer) ClientUIBaseControl 実行時のIDからUIを取得します
game.FindClientUIRoot(nodeName: string) ClientUIBaseControl 指定したUIのルートを取得します
game.GetClientUIRoots() ClientUIBaseControl[] すべてのUIのルートを取得します
game.GetUICanvasSize() x, y: number 画面解像度に応じたUI領域の幅と高さを取得します
game.GetCursorUIPos() x, y: number カーソルのUI座標を取得します

🌸入力とフォーカス

関数 戻り値 内容
game.GetDevice() Device 現在の入力デバイスを取得します
game.SetControllerFocus(control: ClientUIBaseControl) － コントローラーのフォーカスを設定します
game.GetControllerFocus() ClientUIBaseControl 現在のコントローラーのフォーカスを取得します
game.GetControllerLeftStickAxis() horizontal, vertical: number 左スティックの軸値を取得します
game.GetControllerRightStickAxis() horizontal, vertical: number 右スティックの軸値を取得します

🌸Tween、サーバー信号、カスタム変数

関数 戻り値 内容
game.Tween(object: any, tweenDataTable: table, duration: number) Tween Tweenアニメーションを作成します
※指定したオブジェクトのプロパティを一定時間かけて変化させます
※object: 対象オブジェクト
※tweenDataTable: Tween可能なフィールド名をキーとし目標値を値としたテーブル
※duration: 継続時間を引数にします
game.TweenSequence() TweenSequence 空のTweenアニメーションシーケンスを作成します
game.ServerSignal(signalName: string) ServerSignal サーバーへ信号を送ります
game.GetGlobalCustomVariableValue(entityType: CustomVariableEntityType, customVariableName: string) any カスタム変数を取得します

🌸ステージ、効果音、ローカライズ

関数 戻り値 内容
game.PauseLevelTime(pause: boolean) － 1人プレイモードでステージの時間停止状態を設定します
※true: 有効、false: 無効
※スクリプト自体の実行は停止しません（OnUpdate）
game.IsLevelTimePaused() boolean ステージが時間停止状態にあるか確認します
game.PlayAudio2D(audioId: integer) integer 設定済みの効果音IDに従って2D効果音を再生し、 効果音インスタンスIDを返します
game.StopAudio(audioInstanceId: integer) － 指定した効果音を停止します
game.IsAudioAlive(audioInstanceId: integer) boolean 効果音インスタンスが存在しているか確認します
game.GetLanguageType() LanguageType 現在の言語を取得します
game.GetStageMode() StageMode 現在のステージモードを取得します
※Classic, Beyond
game.IsTestPlay() boolean 現在テストプレイであるか確認します
game.GetText(textMapId: string) string 設定済みのテキストマッピングIDに従ってローカライズテキストを取得します
※多言語テキスト管理に設定が必要
