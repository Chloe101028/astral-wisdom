⭐ServerSignal

信号を作成し、サーバーへ送信します。
引数はサーバーの使用に従って順に追加します。

🌸作成

関数 戻り値 内容
game.ServerSignal(signalName: string) ServerSignal サーバーへ送信する信号オブジェクトを取得します

🌸メソッド

メソッド 戻り値 内容
ServerSignal:AddParam(paramType: ParamType, paramValue: any) － paramTypeでパラメータの型、paramValueでパラメータの値を設定します
ServerSignal:SendSignal() － 作成済みの信号を送信します
ServerSignal:AddInt(intValue: integer) － パラメータ(整数)を追加します
ServerSignal:AddIntList(intListValue: integer[]) － パラメータ(整数リスト)を追加します
ServerSignal:AddFloat(floatValue: number) － パラメータ(浮動小数点数)を追加します
ServerSignal:AddFloatList(floatListValue: number[]) － パラメータ(浮動小数点数リスト)を追加します
ServerSignal:AddString(stringValue: string) － パラメータ(文字列)を追加します
ServerSignal:AddStringList(stringListValue: string[]) － パラメータ(文字列リスト)を追加します
ServerSignal:AddVector3(vector3Value: table) － パラメータ(3Dベクトル)を追加します
ServerSignal:AddVector3List(vector3ListValue: table[]) － パラメータ(3Dベクトルリスト)を追加します
ServerSignal:AddBool(boolValue: boolean) － パラメータ(ブール値)を追加します
ServerSignal:AddBoolList(boolListValue: boolean[]) － パラメータ(ブール値リスト)を追加します
ServerSignal:AddGuid(guidValue: integer) － パラメータ(GUID)を追加します
ServerSignal:AddGuidList(guidListValue: integer[]) － パラメータ(GUIDリスト)を追加します
ServerSignal:AddEntity(entityValue: integer) － パラメータ(エンティティ)を追加します
ServerSignal:AddEntityList(entityListValue: integer[]) － パラメータ(エンティティリスト)を追加します
ServerSignal:AddPrefabId(prefabIdValue: integer) － パラメータ(プレハブID)を追加します
ServerSignal:AddPrefabIdList(prefabIdListValue: integer[]) － パラメータ(プレハブIDリスト)を追加します
ServerSignal:AddConfigId(configIdValue: integer) － パラメータ(配置ID)を追加します
ServerSignal:AddConfigIdList(configIdListValue: integer[]) － パラメータ(配置IDリスト)を追加します
