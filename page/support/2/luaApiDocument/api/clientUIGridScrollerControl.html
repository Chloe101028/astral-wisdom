🌸フィールド

フィールド名 型 アクセス 内容

🌸メソッド


リスト項目のインデックスは、実行時に渡されるindexを基準とします。
メソッド 戻り値 内容
RefreshItems(itemCount, refreshCallback) － リスト項目を更新し、項目ごとにコールバックを呼び出します
更新コールバックの形式は fun(control: ClientUIBaseControl, index: integer) で、引数は順に「現在のリスト項目コントロール」と 「リスト項目のインデックス」です
GetItemIndex(control) integer リスト項目のインデックスを取得します。
GetItemSize() x, y: number リスト項目の幅と高さを取得します
GetItemSpacing() x, y: number リスト項目の水平方向および垂直方向の間隔を取得します
GetPadding() top, bottom, left, right: number コンテンツエリアの上、下、左、右の余白を取得します
ScrollToItemAt(index, scrollAlignType) － index の項目へスクロールし、 scrollAlignType に基づいて整列させます
GetContentLength() number スクロール方向におけるスクロールコンテンツの長さを取得します
