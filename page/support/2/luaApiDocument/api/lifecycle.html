⭐スクリプトのライフサイクル

該当の関数を紐づけられたクライアントスクリプト内に記述しておくことで、条件を満たした時に自動的に呼び出されます。
※ノードグラフのイベントノードと同じようなものです。
関数 引数 呼び出し条件
OnInit() － スクリプトの初期化時
OnStrat() － スクリプトの起動時
OnEnable() － スクリプトの有効化時
OnDisable() － スクリプトの無効化時
OnUpdate(dt) dt:number 毎フレーム
※ステージの時間停止の影響を受けません
OnLevelUpdate(dt) dt:number 毎フレーム
※ステージの時間停止の影響を受けます
OnDestroy() － スクリプトの破棄時
*dt: デルタタイム　：前回のフレームから今回のフレームまでに経過した時間
