⭐ClientUIImageControl

画像のカラー、マスク、塗りつぶしの効果を制御します。

🌸フィールド

フィールド名 型 アクセス 内容
imageSource ImageSource 読み取り専用 画像ソース
imageId integer 読み取り専用 画像ID
imageColor ColorValue 読み書き可能 カラー
※Tween可能
imageType ImageType 読み書き可能 画像タイプ
enableMask boolean 読み書き可能 マスキングを有効にするかどうか
enableSoftEdge boolean 読み書き可能 境界線のぼかしを有効にするかどうか
softEdgeMode ImageMaskSoftEdgeMode 読み書き可能 ぼかしモード
softEdgeWidthX number 読み書き可能 水平方向の境界ぼかし幅
※Tween可能
softEdgeWidthY number 読み書き可能 垂直方向の境界ぼかし幅
※Tween可能
horizontalSoftRange number 読み書き可能 横方向エリア範囲
※Tween可能
verticalSoftRange number 読み書き可能 縦方向エリア範囲
※Tween可能
reverseMaskArea boolean 読み書き可能 マスクエリア反転するかどうか
fillType ImageFillType 読み書き可能 塗りつぶしの形状
fillHorizontalType ImageFillHorizontalType 読み書き可能 塗りつぶしの方向(横)
fillVerticalType ImageFillVerticalType 読み書き可能 塗りつぶしの方向(縦)
fillRadial90Type ImageFillRadial90Type 読み書き可能 塗りつぶしの開始位置(90度円軌道)
fillRadialType ImageFillRadialType 読み書き可能 塗りつぶしの開始位置(180度,360度円軌道)
fillAmount number 読み書き可能 進捗
※Tween可能

🌸メソッド

メソッド 戻り値 内容
SetImage(imageSource, imageId) － 画像のソースと画像IDを設定する
SetSoftEdgeWidth(widthX, widthY) － 水平方向および垂直方向のぼかし幅を設定する
SetFillUnused() － 塗りつぶしを使用しないように設定する
SetFillHorizontal(fillHorizontalType, fillAmount) － 水平方向の塗りつぶしを設定する
SetFillVertical(fillVerticalType, fillAmount) － 垂直方向の塗りつぶしを設定する
SetFillRadial90(fillRadial90Type, fillAmount) － 90度円軌道の塗りつぶしを設定する
SetFillRadial180(fillRadialType, fillAmount) － 180度円軌道の塗りつぶしを設定する
SetFillRadial360(fillRadialType, fillAmount) － 360度円軌道の塗りつぶしを設定する
