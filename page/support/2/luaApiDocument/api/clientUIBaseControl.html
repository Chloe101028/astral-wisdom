⭐ClientUIBaseControl

クライアントコントロールのベースクラスです。
階層、レイアウト、スクリプトからのアクセス、入力の監視、およびコントローラー（ゲームパッド）ナビゲーション機能を提供します。

🌸フィールド

フィールド名 型 アクセス 内容
alive boolean 読み取り専用 コントロールが存在しているか
id integer 読み取り専用 実行時ID
prefabIndex integer 読み取り専用 コントロールのテンプレートインデックス
active boolean 読み取り専用 アクティブ状態
true: コントロールは表示され、スクリプトのロジックが実行されます
false: コントロールは非表示となり、スクリプトのロジックも停止します
※デフォルトはfalse
activeInHierarchy boolean 読み取り専用 すべての親要素を考慮した実際のアクティブ状態
visible boolean 読み取り専用 表示・非表示のみを制御し、アクティブ状態やスクリプトロジック実行状態は変更しません
name string 読み書き可能 コントロール名
parent ClientUIBaseControl 読み書き可能 親コントロール
anchoredPositionX,
anchoredPositionY		 number 読み書き可能 位置
※Tween可能
sizeDeltaX,
sizeDeltaY		 number 読み書き可能 サイズ
※Tween可能
anchorMinX,
anchorMinY		 number 読み書き可能 最小アンカー
※Tween可能
anchorMaxX,
anchorMaxY		 number 読み書き可能 最大アンカー
※Tween可能
pivotX,
pivotY		 number 読み書き可能 中心
※Tween可能
localScaleX,
localScaleY,
localScaleZ		 number 読み書き可能 ズーム
※Tween可能
localRotationX,
localRotationY,
localRotationZ 		number 読み書き可能 回転
※Tween可能
canControllerFocus boolean 読み書き可能 コントローラーのスティックによるナビゲーションで選択可能

🌸階層と表示状態


再利用されたリストによって生成された項目については、同階層内での並び順が常に一定であることを保証しません。
メソッド 戻り値 内容
GetChildren() ClientUIBaseControl[] 子のコントロールを取得します
GetChild(name) ClientUIBaseControl カレントコントロール内の指定した名称の子のコントロールを取得します
FindChild(path) ClientUIBaseControl パスに基づいて子のコントロールを取得します
SetActive(active) － アクティブ状態を設定します
非アクティブにするとコントロールが非表示になり、 紐づけされているスクリプトのロジック実行も停止します
SetVisible(visible) － 表示状態を設定します
アクティブ状態には影響しません
GetSiblingIndex() integer 同階層内での並び順インデックスを取得します
戻り値の範囲は0から「親コントロールの子コントロール数-1」です
SetSiblingIndex(index) boolean 同階層内での並び順インデックスを設定します
indexの範囲は0から「親コントロールの子コントロール数-1」です
SetAsFirstSibling() boolean 同階層の先頭に移動します
SetAsLastSibling() boolean 同階層の末尾に移動します

🌸レイアウトと置換


親子階層における移動、拡大縮小、可視性、不透明度、反転、クリッピング効果は、実行時のUI階層によって決定されます。
複合レイアウトを使用する場合は、実際の表示結果を確認してください。
メソッド 戻り値 内容
GetAnchoredPosition() x, y 親階層がない場合はキャンバスの左下を原点として位置を取得し、 親階層がある場合は親階層の中心からの相対オフセットを取得します
SetAnchoredPosition(x, y) － 親階層がない場合はキャンバスの左下を原点として位置を設定し、 親階層がある場合は親階層の中心からの相対オフセットを設定します
GetSizeDelta() x, y サイズの取得
SetSizeDelta(x, y) － サイズの設定
GetAnchorMin() x, y 最小アンカーの取得
SetAnchorMin(x, y) － 最小アンカーの設定
GetAnchorMax() x, y 最大アンカーの取得
SetAnchorMax(x, y) － 最大アンカーの設定
GetPivot() x, y 中心の取得
SetPivot(x, y) － 中心の設定
GetLocalScale() x, y, z ズーム比の取得
SetLocalScale(x, y, z) － ズーム比の設定
GetLocalRotation() x, y, z 回転の取得
SetLocalRotation(x, y, z) － 回転の設定

🌸スクリプトへのアクセス


返されるスクリプトのインスタンスは、破棄され存在していない可能性があります。
使用する前に script.alive で確認してください。
メソッド 戻り値 内容
GetScriptByPath(scriptPath) Script パス指定で紐づけられているスクリプトを取得します
GetScript(scriptMappingId) Script スクリプトマッピングIDでスクリプトを取得します
GetScripts() Script[] コントロール上のすべてのスクリプトを取得します

🌸キーボード・マウス / コントローラーのイベント

メソッド 戻り値 内容
AddNavigationEventListener(eventType, callback) － 監視するコントローラーナビゲーションイベントを登録します
RemoveNavigationEventListener(eventType, callback) － 登録したコントローラーナビゲーションイベントの監視を解除します
RemoveNavigationEventListeners(eventType) － 指定したコントローラーナビゲーションイベントのすべての監視を解除します
RemoveAllNavigationEventListeners() － すべてのコントローラーナビゲーションイベントの監視を解除します

🌸コントローラーナビゲーションの設定

メソッド 戻り値 内容
SetControllerNavigation(navigationDir, navigationMode, navigationTarget) － 指定した方向のナビゲーションモードおよびターゲットコントロールを設定します
ターゲットには nil を指定できます
GetControllerNavigation(navigationDir) navigationMode, navigationTarget 指定した方向のナビゲーションモードおよびターゲットコントロールを取得します
