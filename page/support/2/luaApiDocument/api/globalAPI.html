🌸ログとデバッグ

関数 戻り値 内容
print(...) － 通常ログを出力します
※この関数は処理を中断しません
printerr(...) － エラーログを出力します
※この関数は、エラーではなく処理を中断しません
debug.traceback([message[, level]]) string 現在の呼び出し履歴を文字列として生成します
※message: 文字列の先頭に追加する説明文
※level: 呼び出し履歴の開始階層を指定します
※この関数はログに自動書き込みはしません
game.PrintClientUITree() － 現在のクライアントコントロールの階層構造をログに出力します

🌸数値チェック


外部入力や補間処理で異常な数値が出ていないかチェックすることができます。
関数 戻り値 内容
math.isnan(n) boolean 引数が数値でないか判定します
math.isinf(n) boolean 引数が正または負の無限大かどうかを判定します
